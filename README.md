# 🎓 Student Marks Predictor

> A machine learning model that predicts student academic performance based on study hours and other factors — built using Linear Regression with a full ML pipeline from data cleaning to model evaluation.

---

## 🎯 Problem Statement

Can we predict a student's exam score based on how many hours they study?

This project answers that question using real data and a supervised machine learning approach.

---

## 🔍 What This Project Does

1. **Loads and cleans** student performance data
2. **Explores** the data visually to find patterns
3. **Trains** a Linear Regression model
4. **Evaluates** the model using RMSE and R² metrics
5. **Predicts** exam scores for new inputs

## 🔄 ML Pipeline

```
Raw Data
   ↓
Data Cleaning (handle missing values, remove outliers)
   ↓
Exploratory Data Analysis (visualise distributions, correlations)
   ↓
Feature Selection
   ↓
Train / Test Split (80/20)
   ↓
Linear Regression Model
   ↓
Evaluation (RMSE, R² Score)
   ↓
Prediction on new data
```
